# RIB — Reporte de Informe Biológico de Alimentos

App web para escanear el código de barras de cualquier alimento y obtener un reporte biológico completo: Nutri-Score, NOVA, tabla nutricional, aditivos con nivel de riesgo y alérgenos.

**Base de datos:** Open Food Facts (>3 millones de productos, gratuita y open source)

**Tecnología:** HTML + CSS + JavaScript puro. Sin frameworks.
